# Document Intelligence Platform

A learning-first end-to-end Document Intelligence Platform.

## Goal

Users can upload multiple PDFs and ask questions from those PDFs using RAG.

## Tech Stack

- FastAPI for backend APIs
- Qdrant for vector database
- Python for document processing
- Docker for local development and deployment
- React frontend later
- Git/GitHub workflow for professional development

## Current Milestone

Milestone 1: Backend foundation

## Run Locally with Docker

```bash
docker compose up --build
```
